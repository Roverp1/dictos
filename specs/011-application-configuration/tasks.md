# Tasks: Application Configuration

**Parent documents:** [Specification](./spec.md) · [Technical plan](./plan.md)

**Format:** `[ID] [P?] [US?] Description`

- `[P]`: May run alongside other marked tasks in the same phase after its prerequisites are complete. Tasks editing the same files run sequentially.
- `[US1]`: Inherit shared and client settings with strict validation, defaults, and useful diagnostics.
- `[US2]`: Start with commented configuration files and edit them with generated schema support.
- `[US3]`: Use configured CLI defaults, temporary Model arguments, and the existing CLI logger.
- `[US4]`: Keep Overlay settings stable for one opening while changing its runtime Selected Model.
- `[US5]`: Use English OCR by default and explicitly configured languages when supplied.

Complete each phase before starting the next and follow dependencies within each phase. Paths are relative to the repository root. This feature changes configuration and device-local state contracts; it adds no Dictionary tables or migrations.
