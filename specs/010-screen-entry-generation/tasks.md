# Tasks: Screen Entry and Description Generation

**Format:** `[ID] [P?] [US?] Description`

- `[P]`: Can run alongside other marked tasks in the same phase after its prerequisites. Tasks touching the same files run sequentially.
- `[US1]`: Select and correct an Entry and captured Description on one frozen screen.
- `[US2]`: Edit the drawer with mouse and keyboard, including manual Sense and Descriptions.
- `[US3]`: Suggest Senses and generate reviewed Descriptions from unsaved text.
- `[US4]`: Save the chosen Entry, Sense, and Descriptions atomically, or leave the Dictionary unchanged.
- `[US5]`: Restore overlay-local Instruction/Types, choose a Model, and recover from failures.
